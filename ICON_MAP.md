# AERO Icon Map

Automatically generated map of **640,000 SVG icons** across **8 families** and **729 packs**.

## Quick search

```bash
node scripts/search-icons.mjs settings
node scripts/search-icons.mjs безопасность --category=security
node scripts/search-icons.mjs sword --family=neon
node scripts/search-icons.mjs camera --style=glass
```

For classification rules see [docs/CLASSIFICATION.md](docs/CLASSIFICATION.md).
