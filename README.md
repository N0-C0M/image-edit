# Icons8 UI Icon Agent Kit

Набор правил и каталога для AI-агента, который подбирает иконки для сайтов, приложений, игр и интерфейсов.

> Репозиторий **не зеркалит файлы Icons8**. Иконки остаются у правообладателя и подключаются/скачиваются пользователем через официальный Icons8 UI/API в соответствии с лицензией.

## Отобранные стили

| Приоритет | Пак | Для чего использовать | Официальная страница |
|---|---|---|---|
| 1 | **Claude Hand Drawn** | Основной стиль для SaaS, лендингов, дружелюбных продуктовых интерфейсов, onboarding | https://icons8.com/icons/claude-hand-drawn |
| 2 | **Liquid Glass** | Премиальные современные UI, карточки, hero-блоки, акцентные actions | https://icons8.com/icons/liquid-glass |
| 3 | **Tiny Color** | Компактные панели, dense UI, небольшие контролы и мобильные интерфейсы | https://icons8.com/icons/tiny-color |
| 4 | **Dotted** | Большие интерфейсы, лендинги, editorial/marketing, декоративные элементы | https://icons8.com/icons/dotty |
| 5 | **Puffy Outline** | Игровые, playful и менее формальные интерфейсы | https://icons8.com/icons/puffy |
| 6 | **3D Fluency** | Крупные feature-иконки, empty states, promo-блоки и визуальные акценты | https://icons8.com/icons/3d-fluency |

### Почему именно эти

- **Claude Hand Drawn** — наиболее выразительный и универсальный вариант: живые линии, тёплые акценты, подходит для современного human-centered UI.
- **Liquid Glass** — сильный визуальный акцент для актуального glass/translucent UI.
- **Tiny Color** — лучший кандидат для элементов, где важна читаемость в малом размере.
- **Dotted** — детализированный outline-стиль, хорошо работает там, где иконке дают достаточно пространства.
- **Puffy Outline** — мягкий, игровой и дружелюбный характер.
- **3D Fluency** — не для обычной навигации, зато отлично работает как крупная иллюстративная иконка.

## Структура

- `AGENTS.md` — обязательные правила для AI-агента.
- `catalog/icons8-packs.json` — машиночитаемый каталог паков и рекомендации по применению.
- `docs/ICON_WORKFLOW.md` — workflow выбора, интеграции и проверки иконок.
- `.gitignore` — запрещает случайно коммитить локально скачанные Icons8 assets.

## Быстрый workflow

1. Определи назначение иконки: navigation / action / status / decorative / feature / empty-state.
2. Выбери **один основной стиль на экран**.
3. Найди точную семантическую иконку на официальной странице Icons8.
4. Проверь лицензию своего аккаунта и требования к attribution.
5. Скачай/подключи ресурс официальным способом.
6. Храни локальные Icons8-файлы вне Git или в игнорируемом каталоге `vendor/icons8/`.
7. Проверь размер, контраст, baseline, hover/focus и доступность.

## Лицензия Icons8

Бесплатное использование обычно требует ссылки/атрибуции Icons8. Лицензия также ограничивает распространение исходных assets как отдельных файлов. Поэтому этот репозиторий хранит только метаданные, инструкции и ссылки, а не SVG/PNG самого Icons8.

Официальные условия:
- https://icons8.com/license
- https://icons8.com/terms-and-conditions
- https://developers.icons8.com/docs/getting-started

## Для AI-агента

Перед любым изменением интерфейса прочитай `AGENTS.md`. Не генерируй самодельную замену существующей иконке, если подходящая иконка уже есть в выбранном Icons8 style и пользователь имеет право её использовать.
